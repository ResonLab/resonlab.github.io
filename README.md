# Site de ResonLab

La page d'accueil de la maison : https://resonlab.github.io

Elle présente les quatre briques — Ohmnia, Scenika, Acustika et Nexika — et les
principes communs. Aucune dépendance, aucun build : un fichier HTML et les
logos. Ouvrir la page demande un serveur HTTP (les modules ES ne se chargent pas
depuis `file://`) ; en production, c'est GitHub Pages.

Le style reprend celui du site d'Ohmnia : aurores en fond, révélation au
défilement, boutons à balayage, bascule clair/sombre mémorisée. Une même maison
doit se reconnaître d'un site à l'autre.

Les logos sont les originaux de `Identite/`, copiés ici pour que le dépôt du
site se suffise à lui-même.
